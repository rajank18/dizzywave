# dizzywave

> **geometry becomes music** - a freehand canvas where drawn geometry generates real-time polyphonic audio voices.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- **Interactive Canvas**: Freehand line drawing on canvas.
- **Polyphonic Web Audio Engine**: Scanner column converts drawn line intersections into musical voices.
- **Scale Snapping**: Pentatonic, Major, and Free pitch snapping modes.
- **Tone Selectors**: Bell (sine), Flute (triangle), Synth (sawtooth), Chip (square).
- **Mobile Responsive**: Fully optimized touch controls and mobile Web Audio unlock.
